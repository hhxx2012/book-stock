创建 Supabase 数据库（免费）

创建云端数据库，存所有书本数据

▼
👉 打开 Supabase 注册

用 GitHub 账号登录（没有的话点 Sign Up 用邮箱注册）。

点击 New project → 输入项目名（如 book-system）→ 设置数据库密码（记下来！）→ 区域选 Singapore → 点 Create new project（等待1-2分钟）。

💡 免费版有 500MB 空间，台本系统足够用很多年。

创建完成后，获取两个关键信息：

左侧菜单 → Settings → API，找到：

  • Project URL（https://xxxxx.supabase.co）
  • anon public key（一长串 eyJ...开头的字符）

⚠️ 把这两个值复制到记事本，第3步要用。

然后，创建数据库表：

左侧菜单 → SQL Editor → New query → 把下面的 SQL 全部粘贴进去 → 点 Run：

配置项目连接 Supabase

让项目知道数据库地址

▼

在项目根目录 d:\小程序开发\h5-shubenxitong\ 下创建 .env 文件，写入以下内容：

# 把下面的值替换成你在第1步记录的 VITE_SUPABASE_URL=https://你的项目ID.supabase.co VITE_SUPABASE_ANON_KEY=你的anon-key
💡 替换后重新运行 npm run build 即可生成连接云端数据库的版本。
3

部署到 Netlify（免费）

获得一个网址，任何人打开都能用

▼
👉 打开 Netlify 登录

用 GitHub 账号登录。然后两种方式任选：

方式一：拖拽部署（最简单）

登录后，直接访问 app.netlify.com/drop，把本项目的 dist 文件夹拖进去，等几秒就完成了！

方式二：Git 部署（推荐，自动更新）

  1. 把项目推送到 GitHub 仓库
  2. Netlify 中 → Add new site → Import an existing project → 选 GitHub
  3. Build command: npm run build，Publish directory: dist
  4. 展开 Environment Variables，添加：
    VITE_SUPABASE_URL = 你的Supabase URL
    VITE_SUPABASE_ANON_KEY = 你的anon key
  5. 点 Deploy site
💡 部署完成后，Netlify 会给你一个网址（如 xxx.netlify.app），把这个网址发给同事，大家就能一起用了！
